## Convención de nombres

El nombre usado acá (columna "Persona") debe ser exactamente el mismo que se
usa como `autor` en las bitácoras de cada proyecto y como `nombre` en
`sitio/usuarios.json` — si no coinciden, el panel no puede armar el perfil de
esa persona. Ver `docs/decisiones/002-login-y-control-de-acceso.md`.
